# 🛒 مساعد التسوق الذكي

تطبيق ويب لإدارة التسوق من السوبرماركتات السعودية بذكاء.

## ✨ الميزات

- 💰 **إدارة الميزانية** - تتبع المصاريف الشهرية والمصروف اليومي
- 📚 **كتاب الأسعار** - يحفظ تاريخ الأسعار لكل منتج عبر المتاجر
- 🏷️ **تمييز ذكي** - يفصل بين السعر العادي وسعر العرض المؤقت
- 📊 **مؤشر التضخم الشخصي** - يحسب كم زادت أسعارك بمرور الوقت
- 📱 **تنسيق العائلة عبر واتساب** - بدون سيرفر، بدون اشتراكات
- 📍 **تتبع جغرافي** - يعرف موقع كل سعر تلقائياً من EXIF الصورة
- 🧠 **قاعدة بيانات مُقطّرة** - تنمو معاك بدون استهلاك تخزين

## 🚀 تشغيل محلي على جهازك

تحتاج: [Node.js](https://nodejs.org) (نسخة 18 أو أحدث)

```bash
# 1. تثبيت المكتبات
npm install

# 2. تشغيل التطبيق
npm run dev

# 3. افتح الرابط اللي يطلع في الترمنال (عادة http://localhost:5173)
```

## 🌐 رفع التطبيق على الإنترنت

### الطريقة الأسهل: Vercel (موصى بها)

1. ادخل [vercel.com](https://vercel.com) وسجّل بحساب GitHub
2. اضغط **New Project** → اختر مستودع التطبيق
3. اضغط **Deploy** — Vercel يكتشف الإعدادات تلقائياً
4. خلال دقيقة: راح يعطيك رابط مثل `grocery-hub-xxxx.vercel.app`

### بديل: GitHub Pages

1. عدّل `vite.config.js` وغير `base: '/'` إلى `base: '/grocery-hub/'` (أو اسم مستودعك)
2. شغّل: `npm run build`
3. ارفع محتوى مجلد `dist/` إلى branch اسمها `gh-pages`
4. فعّل GitHub Pages من إعدادات المستودع

## 🔑 تفعيل ميزات الذكاء الاصطناعي (اختياري)

ميزات مسح الفواتير وتحليل تاقات الرفوف تحتاج مفتاح Anthropic API:

1. سجّل في [console.anthropic.com](https://console.anthropic.com)
2. أضف رصيد $5 (يكفي شهر استخدام شخصي)
3. اعمل API Key
4. افتح Console في المتصفح (F12) واكتب:
   ```js
   localStorage.setItem('gh:anthropic_api_key', 'sk-ant-xxxxx');
   ```
5. حدّث الصفحة

⚠️ **تحذير**: حط المفتاح فقط على جهازك الخاص. لا تشاركه ولا تنشره علناً.
